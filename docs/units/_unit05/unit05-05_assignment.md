## Übungsaufgabe 05
 
In dieser Übungsaufgabe wenden Sie die Inhalte aus Lernabschnitt 05 an Ihrem eigenen, aufbereiteten Datensatz an. Sie können auch als Backup die Datei `UE_Temperatur_zusammengefuehrt_20261105_v1.xlsx` nutzen: Die Standortnamen sind bereinigt, Duplikate sind entfernt.
 
Die Übung besteht aus diesen Schritten:
 
1. Berechnen Sie Median und Mittelwert der Spalte Temperatur.  
2. Identifizieren Sie mittels Boxplot über alle Standorte hinweg den größten bzw. niedrigsten **Extremwert** in der Spalte `Temperatur` und ersetzen Sie diese durch den Text `NA`.  
3. Erstellen Sie aus der bereinigten Spalte `Standort` und der Spalte `Temperatur` einen **Boxplot**. Speichern Sie sich das Bild griffbereit ab.  
4. Ersetzen Sie jedes `NA` durch eine leere Zelle und erstellen Sie den Boxplot neu.
5. Werten Sie den korrigierten Boxplot aus. Speichern Sie sich das Bild griffbereit ab.

Führen Sie die Schritte zuerst durch und beantworten Sie dann „Übungsaufgabe 05“ in Ilias.
