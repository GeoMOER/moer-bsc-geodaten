Sie arbeiten mit Ihrer eigenen Arbeitsmappe aus Unit 05 (es sollte jetzt 32 Datenzeilen haben, Zeilen mit fehlender Temperatur sind gelöscht). Es kommen 2 Dateien hinzu: UE_Temperatur_07-07_GS-SP-WR_20260916_v1.csv: Temperaturen im Juli für die drei Stationen, die bisher nur Winterwerte haben
Versiegelung.csv: Versiegelungsgrad im 100-m-Radius um alle Sensoren des Netzwerks (s. auch Kapitel "Verweise" dieser Unit)

Arbeiten Sie auf Kopien der Blätter. Jeder Bearbeitungsstand bekommt ein eigenes Blatt mit vernünftigem Namen.

1) Laden Sie UE_Temperatur_07-07_GS-SP-WR_20260916_v1.csv (Daten → Aus Text/CSV). Prüfen Sie dabei Dateiursprung, Trennzeichen und die Darstellung von Zeit und Temperatur.

2) Bereiten Sie die neuen Temperaturdaten so auf, dass Sie sie an Ihren bisherigen Datensatz anhängen können.

3) Ergänzen Sie in einer neuen Spalte den mittleren Versiegelungsgrad (falls Sie dies schon in der Übung gemacht haben, sollten Sie diesen Schritt mittels drag&drop verkürzen können). Für jeden Standort wurde ein Versiegelungsgrad berechnet!

4) Berechnen Sie mittels  PIVOT Tabelle Anzahl der Messungen pro Datum, mittlere und maximale Temperatur.

a) pro Standort 
b) pro Monat und
c) pro Monat und Standort.  

Notieren Sie sich alle Werte bzw. speichern Sie die Tabelle(n) ab.
