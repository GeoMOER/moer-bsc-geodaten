Ihr Sensordatensatz ist inzwischen bereinigt und zusammengeführt. Die Frage in diesem Kapitel ist eine andere: Könnte eine fremde Person ihn in einem Jahr finden, verstehen und sinnvoll weiterverwenden? Daten sollen langfristig und unabhängig von der Person, die sie erzeugt hat, zugänglich, nachnutzbar und nachprüfbar sein. Das ist auch Teil guter wissenschaftlicher Praxis. Die FAIR-Prinzipien beschreiben, was dafür nötig ist.
 
## Was bedeutet FAIR?
 
FAIR steht für **F**indable, **A**ccessible, **I**nteroperable und **R**eusable, auf Deutsch auffindbar, zugänglich, interoperabel und wiederverwendbar. Die Prinzipien wurden 2016 von Wilkinson und Koautor:innen in der Zeitschrift *Scientific Data* veröffentlicht. Sie sind bewusst nicht nur für Menschen formuliert: Auch Computer sollen Daten selbstständig finden und nutzen können, weil Datenmengen und Komplexität so gewachsen sind, dass man ohne maschinelle Unterstützung den Überblick verliert.
 
| Buchstabe | Leitfrage | Typische Maßnahme |
|---|---|---|
| **F** – Findable | Kann jemand den Datensatz finden? | dauerhafte Kennung (z. B. DOI), ausführliche Metadaten, Eintrag in einem durchsuchbaren Repositorium |
| **A** – Accessible | Wie kommt man an die Daten? | Abruf über ein offenes Standardprotokoll, klar beschriebene Zugangsregeln, Metadaten bleiben auch ohne die Daten erhalten |
| **I** – Interoperable | Lassen sich die Daten mit anderen Daten und Programmen nutzen? | offene Formate (CSV, UTF-8), gemeinsame Konventionen (Einheiten, ISO-Datum, EPSG-Code), Verweise auf andere Daten |
| **R** – Reusable | Darf und kann man die Daten nachnutzen? | klare Lizenz, nachvollziehbare Herkunft, Standards des Fachgebiets |
 
### Die 15 Teilprinzipien in Kurzfassung
 
| Nr. | Kernaussage |
|---|---|
| F1 | Daten und Metadaten haben eine weltweit eindeutige, dauerhafte Kennung |
| F2 | Daten sind mit ausführlichen Metadaten beschrieben |
| F3 | Die Metadaten enthalten die Kennung der Daten, die sie beschreiben |
| F4 | Daten und Metadaten sind in einer durchsuchbaren Ressource registriert |
| A1 | Daten sind über ihre Kennung mit einem standardisierten Protokoll abrufbar |
| A1.1 | Das Protokoll ist offen, kostenfrei und universell umsetzbar |
| A1.2 | Das Protokoll erlaubt bei Bedarf Anmeldung und Zugriffsrechte |
| A2 | Metadaten bleiben zugänglich, auch wenn die Daten nicht mehr verfügbar sind |
| I1 | Daten und Metadaten nutzen eine formale, allgemein anwendbare Sprache |
| I2 | Es werden Vokabulare verwendet, die selbst den FAIR-Prinzipien folgen |
| I3 | Daten verweisen mit qualifizierten Angaben auf andere Daten |
| R1 | Daten sind mit vielen zutreffenden und relevanten Eigenschaften beschrieben |
| R1.1 | Es gibt eine klare, zugängliche Nutzungslizenz |
| R1.2 | Die Herkunft der Daten ist ausführlich dokumentiert |
| R1.3 | Die Daten erfüllen die Standards der jeweiligen Fachgemeinschaft |
